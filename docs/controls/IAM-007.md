# IAM-007 — User consent to applications is unrestricted

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 5.1.5
- **MITRE ATT&CK**: T1528 — Steal Application Access Token

## Logic

Reads the tenant's `AuthorizationPolicy.UserConsentForApps`. Produces a
single tenant-level finding when it is `AllowForAny` — users can consent to
any application requesting any permission, including high-risk ones.

## Known false positives

- If the snapshot has no `authorizationPolicy` (not collected), the control
  produces no finding rather than assuming the worst case.
