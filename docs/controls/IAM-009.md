# IAM-009 — Legacy authentication not blocked by an active Conditional Access policy

- **Severity**: Critical
- **CIS Microsoft 365 Benchmark**: 1.2.2
- **MITRE ATT&CK**: T1110.003 — Brute Force: Password Spraying

## Logic

Passes only if at least one Conditional Access policy is `Enabled`, targets
the `exchangeActiveSync` or `other` legacy client app types, and has a
`block` grant control. A policy left in `Report-only` state does not
satisfy the control — legacy authentication is not actually blocked until
the policy is turned on.

## Known false positives

- None known yet. A tenant that blocks legacy auth through a different
  mechanism (e.g. Security Defaults) instead of a dedicated Conditional
  Access policy will currently be flagged; recognizing Security Defaults is
  a candidate for a future iteration.
