# IAM-014 — Guest invitations allowed for all members

- **Severity**: Medium
- **CIS Microsoft 365 Benchmark**: 5.1.6
- **MITRE ATT&CK**: T1136.003 — Create Account: Cloud Account

## Logic

Reads `AuthorizationPolicy.GuestInviteRestriction`. Produces a single
tenant-level finding when it is `AdminsInvitersAndMembers` or `Everyone` —
i.e. any member can invite a guest without administrator involvement.

## Known false positives

- If the snapshot has no `authorizationPolicy` (not collected), the control
  produces no finding rather than assuming the worst case.
