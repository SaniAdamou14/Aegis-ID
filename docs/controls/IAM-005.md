# IAM-005 — Application secrets or certificates expiring soon, or without expiration

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 1.2.1
- **MITRE ATT&CK**: T1552.001 — Unsecured Credentials: Credentials In Files

## Logic

For every application credential (client secret or certificate), a finding
is produced if it has already expired, expires within 30 days, or has no
expiration date at all. Each credential is evaluated independently, so an
application can produce more than one finding.

## Known false positives

- None known yet — the control only reasons about expiration metadata
  present in the snapshot, not about whether the credential is still in
  active use.
