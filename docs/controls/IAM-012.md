# IAM-012 — Application registration allowed for all users

- **Severity**: Medium
- **CIS Microsoft 365 Benchmark**: 5.1.2
- **MITRE ATT&CK**: T1098.001 — Account Manipulation: Additional Cloud Credentials

## Logic

Reads `AuthorizationPolicy.UsersCanRegisterApplications`. Produces a single
tenant-level finding when it is `true`.

## Known false positives

- If the snapshot has no `authorizationPolicy` (not collected), the control
  produces no finding rather than assuming the worst case.
