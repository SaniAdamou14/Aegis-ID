# IAM-003 — Global Administrator count outside the 2-4 range

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 1.1.1
- **MITRE ATT&CK**: T1078.004 — Valid Accounts: Cloud Accounts

## Logic

Counts users assigned the Global Administrator directory role. Produces a
single tenant-level finding if the count is below 2 (single point of
failure for tenant recovery) or above 4 (unnecessarily wide attack
surface for the most powerful role in the tenant).

## Known false positives

- Does not currently distinguish standing assignments from PIM-eligible
  assignments — that distinction is covered separately by IAM-002.
