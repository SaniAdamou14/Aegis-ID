# IAM-008 — Service principals with no sign-in activity for over 90 days

- **Severity**: Medium
- **CIS Microsoft 365 Benchmark**: —
- **MITRE ATT&CK**: T1078.004 — Valid Accounts: Cloud Accounts

## Logic

For each application, compares `LastSignInDateTime` (the associated service
principal's last sign-in, from Graph's `signInActivity`) to the 90-day
window. Produces a finding only when a timestamp is present and stale.

## Known false positives

- An application with no recorded sign-in activity (`LastSignInDateTime` is
  null) is not flagged — this covers both "genuinely never used" and "sign-in
  activity not available in this snapshot", which cannot be told apart from
  the data alone. Treating null as non-compliant would flood reports with
  false positives whenever sign-in activity hasn't been collected.
