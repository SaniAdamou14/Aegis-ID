# IAM-004 — Missing or non-compliant break-glass account

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 1.1.2
- **MITRE ATT&CK**: T1078.004 — Valid Accounts: Cloud Accounts

## Logic

If no user is flagged `IsBreakGlassAccount`, produces a single tenant-level
finding. Otherwise, for each break-glass account, checks that it (a) has a
hardware-backed authentication method registered (FIDO2 or certificate) and
(b) is excluded from every enabled Conditional Access policy. Either gap
produces a finding for that account listing the specific problem(s).

## Known false positives

- Only FIDO2 and certificate count as "hardware-backed"; Windows Hello for
  Business is deliberately excluded since it is bound to a specific device
  rather than a portable credential.
- Group-based exclusions are not checked — only the account's own user ID
  against each policy's `excludeUsers`.
