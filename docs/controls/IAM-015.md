# IAM-015 — Active user accounts with no sign-in for over 90 days

- **Severity**: Medium
- **CIS Microsoft 365 Benchmark**: 1.1.4
- **MITRE ATT&CK**: T1078.004 — Valid Accounts: Cloud Accounts

## Logic

For each user (excluding break-glass accounts, which are expected to be
dormant), compares `LastSignInDateTime` to the 90-day window. Produces a
finding only when a timestamp is present and stale.

## Known false positives

- A user with no recorded sign-in activity (`LastSignInDateTime` is null) is
  not flagged — this covers both "genuinely never signed in" and "sign-in
  activity not available in this snapshot", which cannot be told apart from
  the data alone. Treating null as non-compliant would flood reports with
  false positives whenever sign-in activity hasn't been collected.
