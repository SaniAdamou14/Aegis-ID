# IAM-011 — Permanent user or group exclusions in Conditional Access policies

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 1.2.x
- **MITRE ATT&CK**: T1562.001 — Impair Defenses: Disable or Modify Tools

## Logic

For each enabled Conditional Access policy, checks its excluded users and
groups. An exclusion of a documented break-glass account (see IAM-004) is
expected and does not produce a finding by itself. Any other user exclusion,
or any group exclusion, produces a finding.

## Known false positives

- None known. A group exclusion is always flagged, since the control cannot
  see inside the group to check whether it only contains break-glass
  accounts.
