# IAM-006 — Applications holding high-risk Microsoft Graph permissions

- **Severity**: Critical
- **CIS Microsoft 365 Benchmark**: 2.1.1
- **MITRE ATT&CK**: T1098.001 — Account Manipulation: Additional Cloud Credentials

## Logic

Flags any application whose granted Microsoft Graph application permissions
intersect a curated high-risk list (`RoleManagement.ReadWrite.Directory`,
`Directory.ReadWrite.All`, `Application.ReadWrite.All`,
`AppRoleAssignment.ReadWrite.All`, `User.ReadWrite.All`, `Mail.ReadWrite`,
`Mail.Send`). The finding lists exactly which of these permissions were
granted.

## Known false positives

- The high-risk list is deliberately conservative for v1; it will need
  periodic review as Microsoft adds new Graph permissions.
- Legitimate automation (e.g. a helpdesk tool needing
  `User.ReadWrite.All`) will still be flagged — this control surfaces risk,
  it does not judge business justification.
