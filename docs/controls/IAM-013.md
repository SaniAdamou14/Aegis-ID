# IAM-013 — Guest accounts holding a directory role

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 5.1.6
- **MITRE ATT&CK**: T1078.004 — Valid Accounts: Cloud Accounts

## Logic

Produces one finding per user whose `UserType` is `Guest` and who has at
least one assigned directory role.

## Known false positives

- None known — a guest holding any directory role is always a finding.
