# IAM-002 — Privileged roles assigned permanently instead of PIM-eligible

- **Severity**: High
- **CIS Microsoft 365 Benchmark**: 1.1.3
- **MITRE ATT&CK**: T1098.003 — Account Manipulation: Additional Cloud Roles

## Logic

For each user, intersects `PermanentAssignmentRoles` (the subset of assigned
roles confirmed as a standing, non-PIM assignment) with the privileged role
list. Produces one finding per affected user. A break-glass account's
finding is marked `expected exception`.

## Known false positives

- `PermanentAssignmentRoles` is not currently populated by the live Microsoft
  Graph collector (`src/Aegis.Graph/GraphTenantCollector.cs`) — distinguishing
  a standing assignment from a currently-activated PIM assignment requires the
  `roleManagement/directory/roleAssignmentScheduleInstances` API, which is not
  yet wired up. Until then, a live scan will never raise IAM-002 findings; the
  field is populated from snapshot files (e.g. the demo tenant) in the
  meantime.
