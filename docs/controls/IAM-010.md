# IAM-010 — Conditional Access policies in report-only mode or disabled

- **Severity**: Medium
- **CIS Microsoft 365 Benchmark**: 1.2.x
- **MITRE ATT&CK**: T1562.001 — Impair Defenses: Disable or Modify Tools

## Logic

Produces one finding per Conditional Access policy whose state is not
`Enabled` — i.e. `ReportOnly` or `Disabled`. A policy in either state
provides no actual enforcement even though it appears configured.

## Known false positives

- A policy genuinely being piloted in report-only mode is still flagged;
  this is intentional — the control tracks enforcement gaps, not intent.
